# lora-geometry

Seminar report typeset with [Typst](https://typst.app) using the
[tracl](https://typst.app/universe/package/tracl) ACL style.

## Build

```sh
# One-off compile to PDF
typst compile main.typ

# Live preview while editing
typst watch main.typ
```

## Files

- `main.typ` — the report source
- `custom.bib` — bibliography entries
